# Plantilla Sidebar

Pequeña plantilla de barra lateral (sidebar) con soporte para modo oscuro, submenús expandibles e iconos, cuenta con responsividad por lo que se puede adaptar a cualquier tamaño de pantalla.

## Características
- Sidebar fijo con estado minimizado/expandido.
- Submenús con animación de altura y control de apertura/cierre.
- Botón para alternar modo oscuro.
- Iconografía con Bootstrap Icons.
